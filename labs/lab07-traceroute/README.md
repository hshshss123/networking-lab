# Lab 07 — Traceroute

## Objective
Understand how traceroute can reveal intermediate routing hops.

## Concepts
- TTL / Hop Limit
- Routing hops
- ICMP responses
- UDP-based traceroute
- Timeouts
- Path visibility

## Exercises
1. Run a traceroute to a safe public destination.
2. Record each responding hop.
3. Note timeouts and repeated hops.
4. Compare the path with another destination.
5. Explain why traceroute does not always reveal every router.

## Questions
- What is TTL?
- Why does traceroute send packets with increasing TTL values?
- Why can a hop show `* * *`?
- Why can two destinations take different paths?
