# Lab 03 — Gateway & Routing

## Objective
Understand how a device chooses where to send IP traffic.

## Concepts
- Routing table
- Default route
- Default gateway
- Destination network
- Next hop
- Local vs remote traffic

## Exercises
1. Try to inspect the routing table.
2. If Android blocks the command, document the exact error.
3. Identify the likely gateway using evidence from your authorized network.
4. Compare traffic to a local address with traffic to an Internet address.
5. Explain why the gateway is needed for remote networks.

## Android Note
Android may restrict access to low-level networking information for ordinary applications. A permission error is an observation about the environment, not proof that routing is absent.

## Questions
- What is a default route?
- What happens when the destination is outside the local subnet?
- Why is the gateway address normally on the local network?
- What evidence is needed before calling an address the gateway?
