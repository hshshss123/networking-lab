# Lab 06 — HTTP & HTTPS

## Objective
Understand how web clients communicate with web servers.

## Concepts
- HTTP request
- HTTP response
- Methods
- Status codes
- Headers
- HTTPS
- TLS
- Hostname

## Exercises
1. Make a simple HTTP/HTTPS request to a safe public website.
2. Inspect the response status and headers.
3. Identify the requested hostname.
4. Compare HTTP and HTTPS conceptually.
5. Explain why HTTPS protects data in transit but does not make every website trustworthy.

## Questions
- What is a request?
- What is a response?
- What does a 200, 301/302, 404, or 500 status generally indicate?
- Why is a hostname important when multiple websites share infrastructure?
